## 🌟 Overview

**CareSphere Health** is a centralized healthcare web platform designed for chronic disease management. It connects **Patients, Doctors, Caretakers, and System Administrators** in one real-time ecosystem.

### Key Capabilities
- 🔐 **Multi-Role Access Control**: Admin, Doctor, Patient, and Caretaker dashboards with role-based routing and quick demo switcher.
- 📊 **Interactive Vitals & Trends**: Real-time charts for Blood Pressure, Fasting Glucose, Heart Rate, SpO2 Oxygen, Weight, and BMI with 7d / 30d / 3m / 6m filters.
- 🤖 **AI-Assisted Risk Analysis Module**: 0–100 risk score engine calculating scores from vitals, chronic conditions, and medication adherence. Includes clear decision-support estimate disclaimers.
- 🧬 **Digital Twin Simulation**: Multi-axis physiological systems radar chart and body system status cards.
- 💊 **Medication & Adherence Tracking**: Daily dose checklist, Taken/Missed toggle, doctor prescription manager, and compliance metrics.
- 🚨 **Automated Alert System**: Real-time flags for abnormal vitals (BP > 140, Glucose > 180, SpO2 < 93%) and acknowledgment workflows.
- 📁 **CSV Dataset Ingestion (Admin)**: Drag-and-drop CSV upload, schema validation, invalid row detection, preview grid, and error report download.
- 🏋️ **Exercise Coach & Daily Missions**: Tailored low-impact exercise routines, activity logging, daily health checklists, and 7-day streak visualizers.
- 📈 **Healthcare Analytics**: Recharts visualizations for cohort demographics, chronic disease prevalence, adherence trends, and appointment statistics.

## 🚀 Quick Start (Local Setup)

```bash
# 1. Clone or extract the repository
git clone https://github.com/your-username/caresphere-health.git
cd caresphere-health

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev

# 4. Open in browser
# http://localhost:3000
```

## 🛠️ Technology Stack

- **Frontend**: React 19, TypeScript, Vite 8, Tailwind CSS, Lucide Icons, Recharts, React Router 7.
- **Data Engine**: Client-side persistent storage layer (`src/db/database.ts`), pre-seeded with 30 patients, 5 doctors, 5 caretakers, vitals logs, and prescriptions.
- **CSV Parser**: PapaParse browser engine for batch ingestion.
